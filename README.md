# Auditoria Fiscal — DF-e e EFD ICMS/IPI

Trilha de estudo em lições curtas (SPED, NF-e/NFC-e, CT-e, MDF-e, tabelas nacionais, EFD e cruzamentos).

## Publicar no GitHub Pages
1. Crie um repositório no GitHub e envie o conteúdo desta pasta (index.html na raiz).
2. Em Settings > Pages, escolha "Deploy from a branch", branch `main`, pasta `/ (root)`.
3. Aguarde a publicação e abra o endereço `https://SEU-USUARIO.github.io/NOME-DO-REPO/` no celular.

O progresso (lições concluídas) fica salvo no navegador do aparelho.
Para editar o conteúdo, altere os arquivos em `licoes/`.
